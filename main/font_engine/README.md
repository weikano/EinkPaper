# FontEngine (ESP32-S3 + ESP-IDF + M5GFX + E-Ink)

## Goals

- Runtime only does file I/O + memcpy + 1bpp bit blit.
- No rasterization/scaling/anti-aliasing on device.
- Supports `.font` generated by `tools/fonts/build_font.py`.
- Supports loading from LittleFS and SDCard.
- Uses PSRAM LRU glyph cache.

## Modules

- `FontFile`: parse `.font` file and read glyph bitmap by offset.
- `GlyphIndex`: Unicode -> offset binary search.
- `GlyphCache`: PSRAM LRU cache.
- `Utf8Decoder`: UTF-8 decode to Unicode codepoint.
- `TextLayouter`: line wrap + line height + baseline.
- `Renderer`: draw 1bpp row-major bitmap to M5GFX target.
- `FontEngine`: facade module.

## `.font` format (from build_font.py)

- `CJK1` (legacy):
  - Header: `magic + glyph_count + width + height + bpp`
  - Index entry: `[codepoint:uint32_le, offset:uint32_le]`
- `CJK2` (current):
  - Header: `magic + glyph_count + width + height + bpp + index_entry_size`
  - Index entry: `[codepoint:uint32_le, offset:uint32_le, advance_x:int16_le, bearing_x:int16_le, bearing_y:int16_le, reserved:uint16_le]`
- Bitmap blob: row-major 1bpp, each row `(width + 7) / 8` bytes

## Example

```cpp
#include "font_engine/FontEngine.h"

font_engine::FontEngine engine;
engine.loadDefaultFontFromLittleFs("cjk_24px_SemiBold_1bpp.font", 256);
engine.drawText(canvas, "你好, FontEngine", 16, 16, canvas.width() - 32,
                TFT_BLACK, TFT_WHITE, false, 4);
```

- `loadDefaultFontFromLittleFs`: auto uses `/littlefs/<name>`.
- `loadFontFromSdCard`: auto uses `/sdcard/<name>` if path is not absolute.
